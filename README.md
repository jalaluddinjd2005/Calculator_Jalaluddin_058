# 🧮 Simple Web Calculator

A clean, responsive, and fully functional web-based calculator built using **HTML5**, **CSS3**, and **JavaScript**. Developed as part of a DevOps workflow assignment demonstrating version control, continuous integration (CI), and web deployment.

## ✨ Features
* **Basic Arithmetic Operations:** Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`).
* **Interactive UI:** Responsive grid layout styled with modern CSS buttons and clear visual feedback.
* **Error Handling:** Gracefully handles invalid mathematical expressions by displaying an "Error" state.

---

## 🛠️ Technologies Used
* **HTML5** — Structure and markup
* **CSS3** — Styling, grid layout, and responsive design
* **JavaScript (ES6)** — Calculator logic and DOM manipulation
* **GitHub Actions** — CI/CD automated workflow
* **GitHub Pages** — Application hosting and delivery
